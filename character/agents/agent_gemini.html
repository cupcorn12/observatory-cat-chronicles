Welcome to the Agent Gemini book

Agent Gemini: she/her, Compass: he/him

Agent Gemini has a cat called Compass, and he follows Leo and Aries to keep up with the work of the Archivists.

Agent Gemini is an Archivist and is known for maintaining the records and keeping up with everyone's nonsense.

Agent Gemini's secret room is an office next to the library and Atlas' office. It is used for her Archivist duties.

Her free time is used up by the shenanigans of the Main Three, but Atlas does double time when that happens so the library doesn't get backed up.
